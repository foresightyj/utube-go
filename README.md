# installation

1. clone this repository
2. run `npm i && npm run build`
3. run `npm link .` and now it is installed as a global npm tool
4. run `utube-go -p urls.txt` any where like below:

```bash
~/Desktop $ utube-go -p urls.txt
totally 1
Sending url 0/1: https://www.youtube.com/watch?v=q3Ies_XTo_s

Done sending 1 urls...
```
